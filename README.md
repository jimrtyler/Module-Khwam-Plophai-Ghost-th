# 👻 Ghost โมดูลความปลอดภัย
**เครื่องมือเสริมความแข็งแกร่งด้านความปลอดภัย Windows & Azure แบบ PowerShell**

> **การเสริมความแข็งแกร่งด้านความปลอดภัยเชิงรุกสำหรับจุดปลายทาง Windows และสภาพแวดล้อม Azure** Ghost มีฟังก์ชันการเสริมความแข็งแกร่งแบบ PowerShell ที่ช่วยลดเวกเตอร์การโจมตีทั่วไปโดยการปิดใช้งานบริการและโปรโตคอลที่ไม่จำเป็น

## ⚠️ ข้อปฏิเสธความรับผิดชอบที่สำคัญ

**ต้องทดสอบ**: ทดสอบ Ghost ในสภาพแวดล้อมที่ไม่ใช่การผลิตเสมอก่อน การปิดใช้งานบริการอาจส่งผลต่อการทำงานทางธุรกิจที่ถูกต้อง

**ไม่มีการรับประกัน**: แม้ว่า Ghost จะมุ่งเป้าไปที่เวกเตอร์การโจมตีทั่วไป แต่เครื่องมือความปลอดภัยใดๆ ก็ไม่สามารถป้องกันการโจมตีทั้งหมดได้ นี่เป็นองค์ประกอบหนึ่งของกลยุทธ์ความปลอดภัยที่ครอบคลุม

**ผลกระทบต่อการดำเนินงาน**: ฟังก์ชันบางอย่างอาจส่งผลต่อการทำงานของระบบ ตรวจสอบการตั้งค่าแต่ละอย่างอย่างรอบคอบก่อนการปรับใช้

**การประเมินจากผู้เชี่ยวชาญ**: สำหรับสภาพแวดล้อมการผลิต ปรึกษาผู้เชี่ยวชาญด้านความปลอดภัยเพื่อให้แน่ใจว่าการตั้งค่าสอดคล้องกับความต้องการขององค์กรของคุณ

## 📊 ภูมิทัศน์ความปลอดภัย

ความเสียหายจาก Ransomware เข้าถึง **57 พันล้านดอลลาร์ในปี 2025** โดยงานวิจัยชี้ให้เห็นว่าการโจมตีที่ประสบความสำเร็จหลายครั้งใช้ประโยชน์จากบริการ Windows พื้นฐานและการกำหนดค่าที่ผิดพลาด เวกเตอร์การโจมตีทั่วไป ได้แก่:

- **90% ของเหตุการณ์ ransomware** เกี่ยวข้องกับการใช้ประโยชน์จาก RDP
- **ช่องโหว่ SMBv1** ทำให้เกิดการโจมตี เช่น WannaCry และ NotPetya
- **มาโครเอกสาร** ยังคงเป็นวิธีการส่งมอบมัลแวร์หลัก
- **การโจมตีแบบ USB** ยังคงมุ่งเป้าไปที่เครือข่ายที่แยกทางอากาศ
- **การใช้ PowerShell ในทางที่ผิด** เพิ่มขึ้นอย่างมากในช่วงปีที่ผ่านมา

## 🛡️ ฟังก์ชันความปลอดภัย Ghost

Ghost มี **16 ฟังก์ชันการเสริมความแข็งแกร่ง Windows** บวกกับ **การรวม Azure ความปลอดภัย**:

### การเสริมความแข็งแกร่งจุดปลายทาง Windows

| ฟังก์ชัน | วัตถุประสงค์ | ข้อพิจารณา |
|----------|---------|----------------|
| `Set-RDP` | จัดการการเข้าถึง Remote Desktop | อาจส่งผลต่อการบริหารระยะไกล |
| `Set-SMBv1` | ควบคุมโปรโตคอล SMB ดั้งเดิม | จำเป็นสำหรับระบบเก่ามาก |
| `Set-AutoRun` | ควบคุม AutoPlay/AutoRun | อาจส่งผลต่อความสะดวกของผู้ใช้ |
| `Set-USBStorage` | จำกัดอุปกรณ์จัดเก็บข้อมูล USB | อาจส่งผลต่อการใช้งาน USB ที่ถูกต้อง |
| `Set-Macros` | ควบคุมการทำงานของมาโคร Office | อาจส่งผลต่อเอกสารที่เปิดใช้งานมาโคร |
| `Set-PSRemoting` | จัดการ PowerShell remoting | อาจส่งผลต่อการจัดการระยะไกล |
| `Set-WinRM` | ควบคุม Windows Remote Management | อาจส่งผลต่อการบริหารระยะไกล |
| `Set-LLMNR` | จัดการโปรโตคอลการแปลงชื่อ | โดยปกติปลอดภัยที่จะปิดใช้งาน |
| `Set-NetBIOS` | ควบคุม NetBIOS บน TCP/IP | อาจส่งผลต่อแอปพลิเคชันเก่า |
| `Set-AdminShares` | จัดการการแชร์ผู้ดูแลระบบ | อาจส่งผลต่อการเข้าถึงไฟล์ระยะไกล |
| `Set-Telemetry` | ควบคุมการรวบรวมข้อมูล | อาจส่งผลต่อความสามารถในการวินิจฉัย |
| `Set-GuestAccount` | จัดการบัญชีแขก | โดยปกติปลอดภัยที่จะปิดใช้งาน |
| `Set-ICMP` | ควบคุมการตอบสนอง ping | อาจส่งผลต่อการวินิจฉัยเครือข่าย |
| `Set-RemoteAssistance` | จัดการ Remote Assistance | อาจส่งผลต่อการดำเนินงาน helpdesk |
| `Set-NetworkDiscovery` | ควบคุมการค้นพบเครือข่าย | อาจส่งผลต่อการเรียกดูเครือข่าย |
| `Set-Firewall` | จัดการ Windows Firewall | สำคัญสำหรับความปลอดภัยเครือข่าย |

### ความปลอดภัย Azure Cloud

| ฟังก์ชัน | วัตถุประสงค์ | ความต้องการ |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | เปิดใช้งานความปลอดภัย Azure AD พื้นฐาน | สิทธิ์ Microsoft Graph |
| `Set-AzureConditionalAccess` | กำหนดค่านโยบายการเข้าถึง | ใบอนุญาต Azure AD P1/P2 |
| `Set-AzurePrivilegedUsers` | ตรวจสอบบัญชีที่มีสิทธิพิเศษ | สิทธิ์ Global Admin |

### ตัวเลือกการปรับใช้องค์กร

| วิธีการ | กรณีการใช้งาน | ความต้องการ |
|--------|----------|--------------|
| **การทำงานโดยตรง** | การทดสอบ, สภาพแวดล้อมขนาดเล็ก | สิทธิ์ผู้ดูแลระบบในเครื่อง |
| **Group Policy** | สภาพแวดล้อมโดเมน | ผู้ดูแลโดเมน, การจัดการ GP |
| **Microsoft Intune** | อุปกรณ์ที่จัดการแบบคลาวด์ | ใบอนุญาต Intune, Graph API |

## 🚀 เริ่มต้นอย่างรวดเร็ว

### การประเมินความปลอดภัย
```powershell
# โหลดโมดูล Ghost
Invoke-WebRequest 'https://raw.githubusercontent.com/jimrtyler/Ghost/main/Ghost.ps1' -OutFile .\Ghost.ps1
Get-Content .\Ghost.ps1
. .\Ghost.ps1

# ตรวจสอบสถานะความปลอดภัยปัจจุบัน
Get-Ghost
```

### การเสริมความแข็งแกร่งพื้นฐาน (ทดสอบก่อน)
```powershell
# การเสริมความแข็งแกร่งที่จำเป็น - ทดสอบในสภาพแวดล้อมห้องปฏิบัติการก่อน
Set-Ghost -SMBv1 -AutoRun -Macros

# ตรวจสอบการเปลี่ยนแปลง
Get-Ghost
```

### การปรับใช้องค์กร
```powershell
# การปรับใช้ Group Policy (สภาพแวดล้อมโดเมน)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# การปรับใช้ Intune (อุปกรณ์ที่จัดการแบบคลาวด์)
Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 🔍 รายละเอียดฟังก์ชัน

### ฟังก์ชันการเสริมความแข็งแกร่งหลัก

#### บริการเครือข่าย
- **RDP**: บล็อกการเข้าถึงเดสก์ท็อประยะไกลหรือสุ่มพอร์ต
- **SMBv1**: ปิดใช้งานโปรโตคอลการแชร์ไฟล์ดั้งเดิม
- **ICMP**: ป้องกันการตอบสนอง ping สำหรับการลาดตระเวน
- **LLMNR/NetBIOS**: บล็อกโปรโตคอลการแปลงชื่อดั้งเดิม

#### ความปลอดภัยแอปพลิเคชัน
- **มาโคร**: ปิดใช้งานการทำงานของมาโครในแอปพลิเคชัน Office
- **AutoRun**: ป้องกันการทำงานอัตโนมัติจากสื่อที่ถอดได้

#### การจัดการระยะไกล
- **PSRemoting**: ปิดใช้งานเซสชัน PowerShell ระยะไกล
- **WinRM**: หยุด Windows Remote Management
- **Remote Assistance**: บล็อกการเชื่อมต่อช่วยเหลือระยะไกล

#### การควบคุมการเข้าถึง
- **Admin Shares**: ปิดใช้งานการแชร์ C$, ADMIN$
- **Guest Account**: ปิดใช้งานการเข้าถึงบัญชีแขก
- **USB Storage**: จำกัดการใช้งานอุปกรณ์ USB

### การรวม Azure
```powershell
# เชื่อมต่อกับผู้เช่า Azure
Connect-AzureGhost -Interactive

# เปิดใช้งานค่าเริ่มต้นความปลอดภัย
Set-AzureSecurityDefaults -Enable

# กำหนดค่าการเข้าถึงแบบมีเงื่อนไข
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# ตรวจสอบผู้ใช้ที่มีสิทธิพิเศษ
Set-AzurePrivilegedUsers -AuditOnly
```

### การรวม Intune (ใหม่ใน v2)
```powershell
# เชื่อมต่อกับ Intune
Connect-IntuneGhost -Interactive

# ปรับใช้ผ่านนโยบาย Intune
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ ข้อพิจารณาที่สำคัญ

### ความต้องการในการทดสอบ
- **สภาพแวดล้อมห้องปฏิบัติการ**: ทดสอบการตั้งค่าทั้งหมดในสภาพแวดล้อมที่แยกเฉพาะก่อน
- **การปรับใช้เป็นระยะ**: ขยายออกไปทีละน้อยเพื่อระบุปัญหา
- **แผนการคืนค่า**: ให้แน่ใจว่าคุณสามารถกลับคืนการเปลี่ยนแปลงได้หากจำเป็น
- **เอกสาร**: บันทึกว่าการตั้งค่าใดที่ใช้งานได้สำหรับสภาพแวดล้อมของคุณ

### ผลกระทบที่อาจเกิดขึ้น
- **ประสิทธิภาพของผู้ใช้**: การตั้งค่าบางอย่างอาจส่งผลต่อเวิร์กโฟลว์ประจำวัน
- **แอปพลิเคชันดั้งเดิม**: ระบบเก่าอาจต้องการโปรโตคอลบางอย่าง
- **การเข้าถึงระยะไกล**: พิจารณาผลกระทบต่อการบริหารระยะไกลที่ถูกต้อง
- **กระบวนการทางธุรกิจ**: ตรวจสอบว่าการตั้งค่าไม่ทำลายฟังก์ชันที่สำคัญ

### ข้อจำกัดด้านความปลอดภัย
- **การป้องกันเชิงลึก**: Ghost เป็นชั้นหนึ่งของความปลอดภัย ไม่ใช่โซลูชันที่สมบูรณ์
- **การจัดการต่อเนื่อง**: ความปลอดภัยต้องการการตรวจสอบและการอัปเดตอย่างต่อเนื่อง
- **การฝึกอบรมผู้ใช้**: การควบคุมทางเทคนิคต้องจับคู่กับการรับรู้ด้านความปลอดภัย
- **วิวัฒนาการของภัยคุกคาม**: วิธีการโจมตีใหม่อาจผ่านการป้องกันปัจจุบันได้

## 🎯 ตัวอย่างสถานการณ์การโจมตี

ในขณะที่ Ghost มุ่งเป้าไปที่เวกเตอร์การโจมตีทั่วไป การป้องกันเฉพาะขึ้นอยู่กับการดำเนินการและการทดสอบที่เหมาะสม:

### การโจมตีสไตล์ WannaCry
- **การลดลง**: `Set-Ghost -SMBv1` ปิดใช้งานโปรโตคอลที่มีช่องโหว่
- **ข้อพิจารณา**: ให้แน่ใจว่าไม่มีระบบดั้งเดิมที่ต้องการ SMBv1

### Ransomware แบบ RDP
- **การลดลง**: `Set-Ghost -RDP` บล็อกการเข้าถึงเดสก์ท็อประยะไกล
- **ข้อพิจารณา**: อาจต้องการวิธีการเข้าถึงระยะไกลทางเลือก

### มัลแวร์แบบเอกสาร
- **การลดลง**: `Set-Ghost -Macros` ปิดใช้งานการทำงานของมาโคร
- **ข้อพิจารณา**: อาจส่งผลต่อเอกสารที่เปิดใช้งานมาโครที่ถูกต้อง

### ภัยคุกคามที่ส่งผ่าน USB
- **การลดลง**: `Set-Ghost -USBStorage -AutoRun` จำกัดการทำงานของ USB
- **ข้อพิจารณา**: อาจส่งผลต่อการใช้งานอุปกรณ์ USB ที่ถูกต้อง

2. **ทดสอบอย่างละเอียด**: ตรวจสอบในสภาพแวดล้อมที่ไม่ใช่การผลิต
3. **วางแผนการคืนค่า**: รู้วิธีการกลับคืนการตั้งค่าแต่ละอย่าง
4. **การตรวจสอบผู้มีส่วนได้ส่วนเสีย**: ให้แน่ใจว่าหน่วยธุรกิจอนุมัติการเปลี่ยนแปลง

### ระหว่างการปรับใช้
1. **แนวทางเป็นระยะ**: ปรับใช้ไปยังกลุ่มนำร่องก่อน
2. **ตรวจสอบผลกระทบ**: ดูข้อร้องเรียนของผู้ใช้หรือปัญหาระบบ
3. **บันทึกปัญหา**: บันทึกปัญหาใดๆ สำหรับการอ้างอิงในอนาคต
4. **สื่อสารการเปลี่ยนแปลง**: แจ้งผู้ใช้เกี่ยวกับการปรับปรุงความปลอดภัย

### หลังการปรับใช้
1. **การประเมินเป็นประจำ**: เรียกใช้ `Get-Ghost` เป็นระยะเพื่อตรวจสอบการตั้งค่า
2. **อัปเดตเอกสาร**: รักษาการกำหนดค่าความปลอดภัยให้เป็นปัจจุบัน
3. **ตรวจสอบประสิทธิผล**: ตรวจสอบเหตุการณ์ด้านความปลอดภัย
4. **การปรับปรุงอย่างต่อเนื่อง**: ปรับการตั้งค่าตามภูมิทัศน์ภัยคุกคาม
